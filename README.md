### 🌐 [Anything Browser](https://github.com/masnavarun18/ANYTHING_BROWSER)
A privacy-focused, high-performance Windows desktop web browser developed by wrapping the Chromium Embedded Framework (QtWebEngine) inside a native Python application.
- **Engine Mechanics:** Powered by Chromium's Blink and V8 pipelines, handling raw media permissions (microphone voice search), High-DPI window scale layers, and standalone execution setups built via PyInstaller.
- **Extension & Signature Control:** Features direct client-side loading of unpacked extensions supporting Manifest V3 rules (uBlock Origin) alongside automated spoofing of HTTP User-Agents and Client Hints to clear web security signatures.
- **Data & Security Infrastructure:** Implemented a secure user profile management dashboard backed by SHA-256 hashed password configurations and localized SQLite state mapping for download queues, browsing history, and bookmarks.
- **DOM Rendering Engine:** Built asynchronous data hooks mapping system theme structures straight into rendered web content for strict color-contrast compliance.
